# LULC Website Design Wireframes

Approved design references for the Urban Land-Cover Change Streamlit project.

## Included pages

- `home-wireframe.html` — narrative home page, methodology, data sources and key findings.
- `explorer-wireframe.html` — full-width interactive map concept, right-aligned year selector, selected-area analysis and contextual locator map.
- `transition-wireframe.html` — essay-style transition analysis supported by focused graphics.

## Shared design system

- White is the principal page colour.
- Pale sage identifies the hero and footer surfaces.
- Navy is used for primary text and navigation.
- Terracotta is reserved for small highlights and active navigation.
- Dynamic World colours are reserved for land-cover data in maps, legends and charts.
- Body copy is dark, left-aligned and comfortably spaced.
- Cards use neutral borders and subtle shadows rather than coloured status borders.

## Intended use

These files are design references, not the final Streamlit implementation. Open each HTML file in a browser while building the corresponding page.
